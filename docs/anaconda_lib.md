# Библиотека Архитектора проекта «Anaconda»

## 1. Чистая Архитектура и Проектирование Систем
Фундамент для построения модульного монолита, который не превратится в хаос.

* **«Чистая архитектура. Искусство разработки программного обеспечения» (Clean Architecture)** — *Роберт Мартин (Uncle Bob)*.
    * *Суть:* Обязательная база. Разделение слоев, инверсия зависимостей.
* **«Архитектура корпоративных программных приложений» (Patterns of Enterprise Application Architecture)** — *Мартин Фаулер*.
    * *Суть:* Классические паттерны (Unit of Work, Repository, Active Record vs Data Mapper), которые используются в ORM и Enterprise-системах.
* **«Архитектурные паттерны в Python» (Architecture Patterns with Python / Cosmic Python)** — *Гарри Персиваль, Боб Грегори*.
    * *Суть:* Как применять DDD и чистую архитектуру именно в Python. Библия для бэкенда на FastAPI.
* **«Высоконагруженные приложения» (Designing Data-Intensive Applications)** — *Мартин Клеппман*.
    * *Суть:* Как работают базы данных, репликация, партиционирование. Критично для связки Postgres + MSSQL + Redis.
* **«Микросервисы. Паттерны разработки и рефакторинга»** — *Крис Ричардсон*.
    * *Суть:* Даже если мы строим монолит, нам нужно знать паттерны коммуникации (Saga, API Gateway), чтобы модули общались правильно.

## 2. Python и Stack-Specific (FastAPI, Asyncio)
Углубленное изучение инструментов.

* **«FastAPI. Веб-разработка на Python»** — *Билл Любанович*.
* **«Python. К вершинам мастерства» (Fluent Python)** — *Лучано Рамальо*.
    * *Суть:* Использование продвинутых возможностей языка, чтобы код был лаконичным и быстрым.
* **«Чистый код на Python» (Clean Code in Python)** — *Мариано Анайя*.
    * *Суть:* Рефакторинг, линтеры, типизация (mypy) и тесты.

## 3. Базы Данных (PostgreSQL, MSSQL, SQL)
Работа с данными — сердце CRM.

* **«PostgreSQL 16 изнутри»** — *Егор Рогов*.
* **«SQL. Библия пользователя» (T-SQL Fundamentals)** — *Ицик Бен-Ган*.
    * *Суть:* Глубокое понимание T-SQL для написания эффективных VIEW и выборок из старой ERP.
* **«Рефакторинг баз данных»** — *Скотт Амблер, Прамод Садаладж*.
    * *Суть:* Как менять схему работающей БД без простоя и потери данных (миграции Alembic).

## 4. Управление Проектами и DevOps (Delivery)
Как доставлять ценность и управлять хаосом.

* **«Проект "Феникс". Роман о том, как DevOps меняет бизнес»** — *Джин Ким*.
    * *Суть:* Художественная книга, идеально описывающая проблемы IT в компаниях и то, как DevOps (CI/CD, IaC) их решает. Очень похоже на вашу ситуацию.
* **«Scrum. Революционный метод управления проектами»** — *Джефф Сазерленд*.
    * *Суть:* Как организовать работу спринтами по 2 недели (как в вашем ТЗ).
* **«Мифический человеко-месяц»** — *Фредерик Брукс*.
    * *Суть:* Почему добавление людей в запаздывающий проект только замедляет его. Классика управления.
* **«Ускоряйся! Наука DevOps» (Accelerate)** — *Николь Форсгрен*.
    * *Суть:* Метрики эффективности разработки (DORA metrics).
* **«Запускаем Ansible» (Ansible: Up and Running)** — *Рене Мозер*.

## 5. Бизнес-литература и Продуктовый подход
Чтобы понимать боли бизнеса и делать продукт, который купят (B2B).

* **«Бизнес с нуля. Метод Lean Startup»** — *Эрик Рис*.
    * *Суть:* Концепция MVP. Почему важно сделать "минимально жизнеспособный продукт" за 4 месяца, а не "идеал" за 2 года.
* **«Спроси маму. Как общаться с клиентами»** — *Роб Фитцпатрик*.
    * *Суть:* Как проводить интервью с менеджерами и инженерами, чтобы понять их реальные проблемы, а не то, что они придумывают.
* **«Разработка ценностных предложений»** — *Александр Остервальдер*.
    * *Суть:* Как технические фичи (AI, чаты) перевести на язык выгоды для бизнеса (экономия времени, ROI).
* **«Цель. Процесс непрерывного совершенствования»** — *Элияху Голдратт*.
    * *Суть:* Теория ограничений. Помогает найти "узкие места" в бизнес-процессах компании (например, выставление счетов).

## 6. Искусственный Интеллект и ML Engineering
Практическое применение AI, а не сухая теория.

* **«Машинное обучение. Паттерны проектирования»** — *Валлаппа Лакшманан*.
    * *Суть:* Как встраивать ML-модели в реальные приложения (отказоустойчивость, версионирование данных).
* **«Глубокое обучение. Легкая разработка на Python»** — *Сет Вейдман*.
* **«Designing Machine Learning Systems»** — *Chip Huyen*.
    * *Суть:* Инженерный подход к ML. Data pipelines, мониторинг моделей в продакшене.
* **Документация и статьи по RAG:**
    * Изучать материалы по ключевым словам: *LangChain, LlamaIndex, Vector Search, pgvector embeddings*.

## 7. CRM и Автоматизация
Специфика предметной области.

* **«CRM со скоростью света» (CRM at the Speed of Light)** — *Пол Гринберг*.
    * *Суть:* Стратегия социального CRM и взаимодействия с клиентами через цифровые каналы.
* **«Data Quality. The Accuracy Dimension»** — *Jack Olson*.
    * *Суть:* Проблема "грязных данных". Как чистить дубли телефонов и email (критично для этапа "Агрегация").
